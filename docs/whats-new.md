# What’s New

Before a stable release, review the diff from the previous stable tag and add verified user-facing highlights to `apps/web/src/whats-new.ts`. Preserve older entries. Use fictional data for any new demonstration screenshots and verify the actual interface before capturing them.

The `/whats-new` website page renders these entries. The browser Help menu links to it. Deploy the selected version’s notes separately before announcing the installer release; installer publication does not deploy the website.
