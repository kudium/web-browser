Google sign-in compatibility and new browser privacy and navigation controls.

- Fix Google sign-in by preserving the real Chromium/Electron browser identity. The previous change passed an authenticated Gmail check; the release regression verifies the public Google sign-in flow.
- Built-in EasyList/EasyPrivacy ad and tracker protection, with bundled offline rules, cached updates, status, and per-site controls.
- Ordered external-link routing to Spaces and groups, with a rule preview in Preferences.
- Copy clean page and link URLs from context menus or Command/Control+Shift+C while preserving signed links and remaining query values.
- Optional automatic picture-in-picture when leaving a playing video, with cleanup on return and preservation of manually opened players.
- Usage and diagnostics now default off and require explicit opt-in on upgrade.

Also includes the previous stable release's workspace improvements:

- Refined favorites, group containment, compact space controls, and search across tabs, groups, collections, and website addresses.
- Reliable folder drops: link a Developer project and open its terminal, or create a sidebar group with the entered name, pages, space, and linked folder.
- Task Manager with live CPU and memory metrics, filters, sorting, context menus, stop/close actions, and force-ending eligible processes.
- Improved notes: wrapped titles, a visual/Markdown view control, quieter options, production loading fixes, and panel recovery.
- General website compatibility based on the real Chromium runtime, reusable primary-color extraction and short caching, and improved default favicons.
- Faster recent-tab toggling, chat opening at the latest messages, and better small-window AI controls.
- More dependable password saving and whole-form autofill, including email fields and broader saved-data browsing.
- Updated website photography and a real browser search recording using public websites and the fictional Atlas Studio project.
